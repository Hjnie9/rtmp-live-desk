# Third-party components

- MediaMTX 1.21.3 runs as a separate process under the MIT license. Its notice is packaged at `server/LICENSE`. [MediaMTX source and release](https://github.com/bluenviron/mediamtx/releases/tag/v1.21.3)
- Flutter and Dart power the application. The Flutter asset bundle includes package and engine notices. [Flutter source](https://github.com/flutter/flutter/tree/3.47.9)
- media_kit loads libmpv and provides the Flutter video texture. Its Windows native package specifies the archives and their hashes. [media_kit source](https://github.com/media-kit/media-kit) · [Pinned native package](https://pub.dev/packages/media_kit_libs_windows_video/versions/1.0.11)
- The Windows libmpv binary uses mpv commit `652a1dd90711839acdccc08004056d25514ef2d8`. Its build project includes the dependencies, patches and build instructions. [Corresponding mpv source](https://github.com/mpv-player/mpv/tree/652a1dd90711839acdccc08004056d25514ef2d8) · [Windows build source](https://github.com/media-kit/libmpv-win32-video-build) · [Binary archive](https://github.com/media-kit/libmpv-win32-video-build/releases/tag/2023-09-24)
- The Windows video texture uses ANGLE and its accompanying libraries from the archive selected by media_kit. [ANGLE source and license](https://github.com/google/angle) · [Windows binary archive](https://github.com/alexmercerind/flutter-windows-ANGLE-OpenGL-ES/releases/tag/v1.0.1)
- The Windows bundle includes the Microsoft Visual C++ redistributable runtime libraries. [Microsoft redistribution information](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files)
